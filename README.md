# Glosario

## 1. Almacenamiento
Es el proceso de guardar datos e información dentro de un dispositivo para poder usarlos.  
Puede ser interno, como el disco duro, o externo, como una memoria USB.

## 2. Administrador de bases de datos
Es la persona encargada de organizar, mantener y proteger las bases de datos de una empresa o sistema.  
Se asegura de que la información esté segura y que funcione correctamente.

## 3. Bases de datos
Se almacenan en un sistema para poder consultarlas y administrarlas fácilmente.  
Permite guardar información de manera ordenada.

## 4. Componentes
Son las partes que forman un sistema de cómputo y permiten que funcione correctamente.  
Incluyen tanto el hardware como el software.

## 5. Contenedores
Son espacios o entornos donde se guardan y ejecutan aplicaciones junto con todo lo que necesitan para funcionar.

## 6. Ciberseguridad
Es el conjunto de medidas que se usan para proteger computadoras, redes y datos contra ataques o accesos no autorizados.  
Ayuda a evitar robos de información, virus y hackeos.

## 7. Código embebido
Es un programa que está integrado dentro de un dispositivo para que pueda funcionar correctamente.

## 8. Desarrollador de software
Es la persona que crea y programa aplicaciones o sistemas para computadoras.  
Se encarga de escribir el código, probarlo y corregir errores.

## 9. Hardware
Es la parte física de la computadora que se puede ver y tocar.  
Incluye dispositivos como el monitor, teclado, mouse y CPU.

## 10. Internet y la web
Internet es la red mundial que conecta computadoras y dispositivos en todo el mundo.  
La web es un servicio que funciona dentro de Internet y permite acceder a páginas y sitios web.

## 11. Nube
Es un servicio que permite guardar información y usar programas a través de Internet sin tenerlos en la computadora.

## 12. Software
Es el conjunto de programas y aplicaciones que hacen que la computadora funcione.  
No se puede tocar, porque es la parte lógica del sistema.

## 13. Servicios
Son funciones o recursos que un sistema ofrece para realizar una tarea específica, como servicios en línea, almacenamiento en la nube o correo electrónico.

## 14. Seguridad
Es el conjunto de medidas que se toman para proteger la información y los sistemas de cómputo.

## 15. Servidor
Es una computadora o sistema que ofrece servicios, recursos o información al mismo tiempo.
